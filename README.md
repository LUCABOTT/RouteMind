# RouteMind

**Plataforma de gestión y seguimiento de pedidos y vehículos.**

RouteMind es un proyecto de desarrollo web Full Stack orientado a la gestión de pedidos y vehículos, con una arquitectura organizada en frontend y backend.

## Tecnologías

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- NestJS
- TypeScript
- Sequelize
- PostgreSQL

### Infraestructura
- Docker
- Docker Compose
- Git y GitHub

## Funcionalidades

- Gestión de pedidos.
- Gestión de vehículos.
- Asociación de vehículos con pedidos.
- API REST para la comunicación entre frontend y backend.
- Base de datos PostgreSQL.

```text
RouteMind/

├── frontend/
│   ├── src/
│   └── package.json

```

## Instalación y ejecución

1. Clona el repositorio.
2. Configura las variables de entorno siguiendo el archivo `backend/.env.example`.
3. Instala las dependencias del backend y frontend.
4. Inicia los servicios necesarios con Docker Compose.
5. Ejecuta el backend y frontend según sus respectivos archivos README.
